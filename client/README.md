# MediTrack

A modern family health management application built with React and Vite.

## Features

- Family member profiles and health tracking
- Medication database and scheduling
- Appointment management
- Health reports and documents
- Analytics and insights
- Dark mode support

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Recharts
- Lucide React Icons
